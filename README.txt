# Protótipo do Delivery de Açaí

Abra `index.html` no navegador para testar.

O protótipo já possui:
- cardápio responsivo para celular;
- carrinho;
- quantidades;
- checkout com nome, WhatsApp, endereço, pagamento e observação;
- geração de número do pedido;
- simulação de recebimento do pedido.

Próxima etapa para produção:
1. criar backend/banco de dados;
2. criar painel da loja;
3. conectar pedidos em tempo real;
4. integrar uma impressora térmica (idealmente via computador/servidor local);
5. configurar taxa de entrega e meios de pagamento reais;
6. publicar o site em um domínio.
